## Featured project

### [IoT Federated Learning with Zero-Knowledge Proofs](https://github.com/mohamed-shaheen1/iot-federated-learning)

A bachelor-thesis research prototype for distributed IoT intrusion detection. It compares centralized and federated training, explores non-IID data and poisoned clients, and includes an experimental ZoKrates proof workflow.

- Interactive local dashboard with live training, comparison curves, confusion matrices, and replay
- Reproducible synthetic demo plus support for the UNSW-NB15 dataset
- 19 automated tests covering training, aggregation, preprocessing, dashboard APIs, and security controls
- Honest documentation of the prototype's cryptographic and research limitations

**Tech:** Python · NumPy · scikit-learn · Federated Learning · ZoKrates · HTML/CSS/JavaScript
